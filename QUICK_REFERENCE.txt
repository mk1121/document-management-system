DEPLOYMENT OPTIONS

1️⃣  WEB ONLY (PWA)
   • Host on Vercel, Heroku, or self-hosted Node.js
   • Command: vercel --prod
   • Time: 2-5 minutes
   • Cost: Free (Vercel) to $$$

2️⃣  ANDROID ONLY (APK)
   • Distribute on Google Play Store or direct download
   • Requires: Java, Android SDK, Gradle
   • Time: 30 minutes (debug), 1+ hour (release)
   • Cost: $25 Google Play Developer Account

3️⃣  HYBRID (RECOMMENDED)
   • Web + APK both available
   • APK points to web API
   • Best user reach
   • Maintenance: Single codebase

TROUBLESHOOTING

Build fails?
  → rm -rf .next && bun run build

APK build fails?
  → cd android && ./gradlew clean && cd .. && bun run build

API connection issues?
  → Check NEXT_PUBLIC_API_BASE_URL in .env
  → Verify CORS in browser console

Service Worker not working?
  → Clear browser cache: DevTools → Application → Clear storage
