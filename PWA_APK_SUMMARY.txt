🎯 Quick Start Guide
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Test PWA Locally
  $ bun run dev
  → Open http://localhost:3000
  → Click install icon in browser

Step 2: Build Production PWA
  $ bun run build:pwa

Step 3: Setup Android (First Time Only)
  $ bunx cap init
  $ bunx cap add android
  $ bun run android:sync

Step 4: Generate APK
  $ bun run build:android:debug    (for testing)
  $ bun run build:android:release  (for distribution)

  Download: https://www.oracle.com/java/technologies/downloads/

□ Android SDK
  Download: https://developer.android.com/studio

Environment Variables:
  export JAVA_HOME=/path/to/jdk17
  export ANDROID_SDK_ROOT=$HOME/Android/Sdk
  export PATH=$ANDROID_SDK_ROOT/cmdline-tools/latest/bin:$PATH
